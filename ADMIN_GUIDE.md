# PAWIN Admin Portal Guide

This document contains all the necessary details for managing and maintaining the PAWIN Admin Command Center.

## 1. Accessing the Portal
- **URL**: `https://pawinplc.com/#/admin-login` (or `http://localhost:5173/#/admin-login` in development)
- **Requirements**: You must have an account in the Supabase Auth system and your record in the `public.profiles` table must have the `role` set to `'admin'`.

## 2. Database Schema Requirements
The Admin Dashboard interacts with the following Supabase tables:

### `profiles`
Stores user identity and roles.
- `id`: UUID (Primary Key, references auth.users)
- `email`: Text
- `full_name`: Text
- `role`: Text (Options: 'member', 'admin')

### `applications`
Stores registrations from innovators and investors.
- `id`: BigInt/UUID (Primary Key)
- `full_name`: Text
- `email`: Text
- `interest_type`: Text (e.g., 'innovator', 'investor')
- `created_at`: Timestamp

### `contact_messages`
Stores inquiries from the contact form.
- `id`: BigInt/UUID (Primary Key)
- `full_name`: Text
- `email`: Text
- `subject`: Text
- `message`: Text
- `created_at`: Timestamp

## 3. Promoting a User to Admin
To grant someone admin access, run this SQL in the Supabase SQL Editor:
```sql
UPDATE profiles SET role = 'admin' WHERE email = 'user@example.com';
```

## 4. Troubleshooting "Failed to Fetch Data"
If you see this error, it usually means one of the tables above is missing from your Supabase project. You can create them using the following SQL:

```sql
-- Create Applications Table
CREATE TABLE IF NOT EXISTS public.applications (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  full_name TEXT NOT NULL,
  email TEXT NOT NULL,
  interest_type TEXT NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- Create Contact Messages Table
CREATE TABLE IF NOT EXISTS public.contact_messages (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  full_name TEXT NOT NULL,
  email TEXT NOT NULL,
  subject TEXT,
  message TEXT NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);
```

## 5. Security Best Practices
- **Password Policy**: Admins should use complex passwords (12+ characters).
- **Session Management**: Always click the **Logout** button when finished to clear your local session.
- **RLS**: Ensure Row Level Security is enabled on all tables, but allowed for the Admin Dashboard to perform SELECT and DELETE operations.
